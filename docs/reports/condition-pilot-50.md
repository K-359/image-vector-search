棄却は1画像で発生し、自転車の乗り手を歩行者として記載する一方で歩行者不在を報告していました。再試行時に矛盾の内容と乗り手の規約を具体的に伝え、成功済み49枚を再処理せずに1枚だけ再生成しました。

以前の約13時間という5,000枚の見積もりは、旧方式の出力量からの参考値です。

**今後の教師処理は約24〜28時間を暫定参考値とします。** 50枚は難しい画像を意図的に含む試行で、5,000枚の構成・再試行率・仕様変更で変わります。
候補画像の確認、独立した評価注釈、学習の時間は含みません。途中の確認や再開待ちを含む壁時計上の経過時間と、上表の処理実行時間も別です。

## 3. 品質確認の結果

12/50画像を要確認に分離しました。項目は重複するため下表の合計は12と一致しません。
これは12枚すべてが誤りと確定したという意味でも、残り38枚の全ラベルが正しいと確認したという意味でもありません。

| 確認事項 | 画像数 |
|---|---:|
| 乗り手を歩行者として記載した疑い | 6 |
| 昼・夜・薄明の判定が矛盾 | 2 |
| 24個体の記載上限に到達 | 2 |
| 同じ対象根拠文を4回以上反復 | 3 |
| 元画像との照合で要確認 | 2 |

具体的な確認例:

- `e9a2b037-7ea99618`: 赤い尾灯の強い光を車体色と同一視せず、赤い車の条件は判定不能でした。
- `4c0dee56-c311cb85`: 視認できる歩行者は画面中央にあり、「画面左の歩行者」を不適合とした結果は観察と整合しました。
- `6c579b9e-29c890e5`: 路肩・斜面に雪があり主要な走行部分は乾いて見えます。説明文も「車道は除雪され乾いたアスファルト」としていますが、`snow_on_road=yes`でした。説明とラベルの不整合として保留しました。
- `c7aa5575-4706c0d1`: 二輪車の乗り手を歩行者として別個体に記載しており、規約と不整合です。二輪車の種類の識別も要確認です。
- `f733f7fc-98691a7c`: 遠方に多数の車がある画像で24個体の上限に達し、車の根拠文が反復しました。多数の車が実在することと、各個体の種類・色・矩形が正しいことは別なので保留しました。

自動検査では対象記載の反復・上限到達・時間帯の矛盾・乗り手らしい根拠文を検出します。
元画像との照合で見つかった問題も`pilot/quality_reviews.jsonl`から集約し、該当画像の候補判定を`review_required`にします。
元の教師出力は変更していません。

# 検索条件一覧の拡張 v1

確定日: 2026-09-28

[検索条件一覧 v1](search-condition-catalog.md) に足す条件です。
条件一覧を見ずに書かれたクエリで網羅率を測ったところ、今の語彙で表せるのは7〜9%でした（[網羅率の節](reports/condition-paraphrase-bdd-eval.md#5-条件一覧の網羅率)）。
表せない理由のうち、画像1枚で判定でき、かつ実際に絞り込む条件になる次の2つを足します。

- **駐車している乗り物**（自由文の14%が「駐車」「路肩に停車」を含みます）
- **黄色・緑色の乗り物**（自由文の7%・3%が含みます）

v1 の条件・画像・ラベルは変えません。
新しい属性は v3 の画像5,000枚に追加の注釈として付けます（`scripts/annotate_extension_facts.py`）。

## 判定規約

- **駐車**: 走行する車線の外に停めてあることを要求します。
  - 路肩・駐車場・駐車枠・道路脇の駐車の列、歩道側に寄せて停めてある、駐輪されている、などの根拠が要ります。
  - 走行車線上で信号待ちや渋滞で止まっている乗り物は、駐車ではありません。
  - 止まっているか動いているかを推測では決めません。
- **黄・緑**: 車体の主な塗装色です。規約は v1 の色と同じで、照明・反射・乗り手の服の色は使いません。
  - v1 の注釈で白・黒・赤・青とされた対象は、黄・緑ではないものとして扱います。
- 画像の高さの2.8%（720pxの画像で20px）より低い枠では、駐車も黄・緑も判定不能とします。
- 対象外のまま残すもの:
  - 走行車線上での停車・走行などの動き（静止画では判定が難しいため）
  - 銀色（白との区別があいまいなため）
  - 車種の細分類（セダン・SUV・タクシーなど）
